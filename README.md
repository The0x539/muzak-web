dependencies:
- rust
- [`wasm-pack`](https://drager.github.io/wasm-pack/installer/) to build the rust/wasm stuff
- [`deno`](https://docs.deno.com/runtime/getting_started/installation/) to run the dev server (optional - any basic http server should work tbh)

to run:
- `deno task build`
- `deno task run`
- http://localhost:8000
